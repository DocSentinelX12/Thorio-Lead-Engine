# Predictive Healing Intelligence\n\n## Goal\n\nAdd a production-connected predictive layer that discovers useful signals from the existing authoritative healing evidence graph, learns failure relationships, produces transparent path-scoped risk assessments, and generates counterfactual explanations without becoming a physical or execution source of truth.\n\n## Architecture\n\nAuthoritative observations -> Healing Evidence Graph -> Signal Discovery -> Historical relationship learning -> Failure-risk prediction -> Counterfactual analysis -> Healing Intelligence scheduling -> Continuous Recovery\n\n## Constraints\n\n- Exact fabric path identity remains authoritative in ComputeInventory and PhysicalFabric.\n- Predictions never authorize unsafe physical changes by themselves.\n- Insufficient evidence produces INSUFFICIENT_EVIDENCE, not a guessed probability.\n- Every learned signal retains source observations and sample counts.\n- Counterfactuals are explanatory only unless an existing safety governor independently authorizes the action.\n- Existing known-good recovery remains continuously available.\n\n## Learning\n\nFor each numeric signal discovered in evidence payloads, the engine maintains healthy and failure distributions. A signal becomes predictive only when both classes have sufficient observations. Effect size is normalized using pooled standard deviation. The risk contribution is bounded and combined conservatively.\n\nThe engine also discovers categorical state transitions such as state and measurement_status, preserving their source authority and observation timestamps.\n\n## Prediction\n\nThe assessment contains prediction state, failure risk when evidence is sufficient, confidence, signal contributions, discovered relationships, source observation IDs, evidence age, and counterfactual risk deltas for replacing active signals with learned healthy baselines.\n\nNo prediction is emitted as a precise probability when training evidence is insufficient.\n\n## Integration\n\nHealingIntelligence consumes the predictor. High predictive risk increases scheduling serialization, but cannot bypass protected-capacity or authoritative verification requirements. ContinuousRecovery records the predictive assessment with the episode so decisions remain auditable.\n\n## Verification\n\nTests cover discovery, learned signal relationships, insufficient evidence, prediction determinism, counterfactuals, restart persistence, exact-path provenance, and integration with healing planning and continuous recovery.
